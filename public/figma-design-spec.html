Berapa batas baku mutu massa jenis Pertamax (RON 92) pada suhu 15°C menurut Kepmen ESDM?

Berdasarkan Keputusan Dirjen Migas No. 245.K/MG.01/DJM/2022, spesifikasi Massa Jenis @15°C untuk Pertamax (RON 92) adalah:

Cara Mengimpor Desain ke Figma (10 Detik)

1 Install Plugin "html.to.design" di Figma

Buka Figma → Plugins → Cari dan jalankan html.to.design (atau Builder.io HTML to Figma).

2 Import File HTML Ini

Pilih opsi Import HTML File di plugin tersebut, lalu pilih file public/figma-design-spec.html ini.

3 Import Token Variables

Gunakan file public/figma-tokens.json untuk mengimpor seluruh token warna, typography, dan spacing ke Figma Variables.
